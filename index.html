Proyecto de contenedores de Ariana

Servidor Docker · Docker Compose y aplicaciones multicontenedor

📌 Los 3 Servicios del Proyecto
Servidor web
Activo

Nginx (ariana-web) publicado en el puerto 8080. Esta es la página que estás viendo.

Aplicación
Activo

PHP aislado (ariana-app) con el volumen datos_app mapeado de forma de forma persistente.

Base de datos
Activo

MariaDB 11 (ariana-db) con la base proyecto y volumen datos_db protegido.

🔒 Red y Persistencia
red_app
Red

Red aislada creada por Compose. Los contenedores se comunican internamente por nombre de servicio.

datos_app
Volumen

Persiste el almacenamiento y código de la aplicación ante cualquier reinicio.

datos_db
Volumen

Persiste de forma segura las tablas e índices relacionales de MariaDB.

💻 Instalado en el Servidor
Ubuntu Server
Base

Servidor anfitrión de las prácticas, administrado remotamente por SSH.

Docker Engine
Motor

Entorno en producción encargado del ciclo de vida de las imágenes y runtimes.

Docker Compose
Plug-in

Orquestador encargado de levantar la infraestructura mediante el manifiesto YAML.
